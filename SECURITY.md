# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately instead: the
"Report a vulnerability" button on the [Security tab](https://github.com/churnast/hermes-memory-shield/security/advisories/new) of this
repository. We will reply as soon as we can.

Helpful details: Hermes Agent version, plugin version, steps to reproduce and what an attacker could
achieve.

## In scope

Ways to change or delete protected memory despite the policy, to read the log or snapshots of another Hermes profile, or to make the plugin write outside its own data folder.
